# Advance Design 3D Viewer

🇫🇷 [🇬🇧](README_EN.md)

Visualiseur 3D pour les modèles Advance Design.

<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/084a2d40-3d2b-4fa9-beca-dde87c08598c" />


## Fonctionnalités

- Visualisation 3D
- Sélection d'objets
- Extraction des propriétés
- Métré automatique
- Métré par matériau
- Résultats sur appuis (ponctuels, linéaires et surfaciques), résultats sur les voiles (torseurs) et sur les éléments filaires (diagrammes)
- Export des résultats au format .xlsx
- Export IFC
